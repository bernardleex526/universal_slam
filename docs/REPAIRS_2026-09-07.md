# 2026-09-07 确定性阻断修复

基线提交：708c83b3e34f31bac9550cfff5cb60b2e576e28b。主仓库本轮改动未提交/推送。

## 已修复

1. Nav2 costmap 参数移到独立 ROS 节点根；局部6x6m、全局40x40m滚动窗口；无静态地图层；实际参数探针已验证。
2. Type/Command 从 PatrolDevice JSON 解析，头部仅保留报文ID和格式标志。原有错误造包测试已替换为官方结构。
3. UDP 控制重写为显式使能、人工解锁、健康状态门控；不自动起立/切模式/切步态。速度安全限值与满量程独立，满量程必须与 expected_gait 对应。
4. 状态、里程计、指令超时以及 NaN/Inf 会锁止。恢复状态不自动解锁。无状态不能解锁，仿真不能启动控制。
5. RoboSense timestamp float64绝对秒 -> time float32相对秒；按逐点时间排序，保留真实ring。空IMU帧名只在profile明确允许时接收。
6. 源QoS可配置，归一化点云/IMU输出及FAST-LIO输入为reliable。本机大点云在best_effort路径完全丢失，已通过回放找到并修复该链路问题；未修改全局内核参数。
7. FAST-LIO输出真实线速度和角速度，协方差在发布前填写；底盘适配器转换位姿/杆臂速度/协方差，只有它发布全局odom->base_link。
8. 原生FAST-LIO TF保留在私有话题；自研默认使用uslam前缀。机型参数贯穿Nav2速度、TF、传感器和控制话题。
9. 地图改为有界、体素化的全会话累积，独立于可视化定时器；空地图、容量不足、写盘错误返回失败；临时文件原子替换。
10. 保存客户端查询实际路径，拒绝旧文件/空地图。转换工具使用独立话题和有界等待。
11. 构建脚本扫描全部包，初始化子模块；第三方patch已验证干净checkout应用与重复应用。
12. SW01自动申请控制权已禁用；缺SDK时仍不构建运行节点，不把纯函数测试当作SDK验收。

    https://drive.google.com/drive/folders/19T__ai6u5WCTwyWi3L4KC9gVZI-jiQM-

下载文件 lidar_data_bag_0.db3 + metadata.yaml。452条点云、8301条IMU，约45.3秒；点云ring0..191，timestamp为绝对秒；IMU帧为空。整包存在53次点云header时间不递增，适配器会拒绝非单调扫描而非伪造时序。

官方配置给出的单位外参仅用于离线参考。它没有证实当前M20 Pro中该融合点云与身体/IMU的真实外参，故现场profile仍未解锁导航。

## 验证类别

- 单测/集成测试：协议、默认不发控制指令、无反馈禁止解锁、实际限幅、失联零速、恢复不自动解锁、点云字段转换、TF数学与所有权、Nav2参数接线、空地图保存不崩溃。
- 实际bag：完整回放、有限且单调的里程计、唯一动态TF、非空PCD保存；轨迹CSV和结果JSON由 replay_smoke.py 输出。
- 运行时Nav2参数：探针进入configure读取真实参数，不依赖YAML静态检查。
- 构建：Humble/WSL x86_64；SW01缺SDK，仅构建该包的纯函数测试。
